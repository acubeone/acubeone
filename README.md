# Hello humans! I'm aCube!

Yo! I'm aCube, just another Brazilian guy who loves games and retro hardware. I started in 2020 making games in Lua on the TIC-80 fantasy computer, using nothing but an Android phone. Curiosity kept pulling me down the stack. First came emulators, then hardware and electronics, and now I'm here building custom CPUs, emulators, tools and games, mostly in C. My brain loves a deep dive, and retro aesthetics are a favorite one. I love to teach what I know, so ask me anything!!

## Projects

| Project | What it is | Status |
| --- | --- | --- |
| **AX8** | Custom 8-bit ISA and CPU designed from scratch: instruction encoding, control logic and register layout. Verilog with simulation testbenches, plus a two-pass assembler in C. | In progress |
| **M68K emulator** | Emulation layer for the Motorola 68000, with variable-length instruction parsing, exception vectors and a virtual memory bus. Written in C. | In progress |
| **MOS 6502 core** | Cycle-accurate CPU core with all legal opcodes, status flags, stack operations, page-boundary cycles and IRQ/NMI. Written in C. | In progress |
